# Bundled website fonts

These files replace build-time Google Fonts downloads. `next/font/local` serves the same Source Sans 3 and Cormorant Garamond families from the application's static assets.

The unmodified Latin variable WOFF2 files were obtained from npm packages `@fontsource-variable/source-sans-3@5.3.1` and `@fontsource-variable/cormorant-garamond@5.3.0`. Each font's SIL Open Font License is retained in this directory. Package installation verifies the registry artifact integrity; the assets are committed so deployment does not contact Google or Fontsource.
